# Library Management System Backend

This is the backend for a Library Management System built using Node.js, Express, and MySQL.

## Features

- User and Admin authentication
- Book search and management
- Loan requests and management
- Fine tracking and payment
- Reviews and ratings
- Interlibrary loan requests

## Prerequisites

- Node.js (v14 or higher)
- MySQL (v5.7 or higher)
